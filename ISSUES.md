# Issues

- ISA out-of-date
	- The current implementation of the emulator is based on an older version of the ISA specification. This has led to discrepancies between the emulator's behavior and the expected behavior as defined in the latest ISA documentation. To address this issue, we need to update the emulator's codebase to align with the latest ISA specifications, ensuring that all instructions and features are correctly implemented and tested against the updated documentation.
